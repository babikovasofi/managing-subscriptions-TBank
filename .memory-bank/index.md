# Memory Bank — index

Оглавление для агентов харнесса (planner, skeptic, reviewer, debugger, исполнители).
Сам источник правды — файлы ниже. Здесь ничего не дублируем, только ссылки.

## Проект
- **Что:** хакатон Т-Банка (ТОПИТ), кейс «Управление подписками». Находим вероятные подписки в истории операций, объясняем регулярность, показываем уверенность, прогнозируем дату списания, предупреждаем о росте цены и конце пробного периода.
- **Стек:** Python (pandas, LightGBM, FastAPI, sync SQLAlchemy + SQLite) · Next.js 14 + React 18 + Tailwind · Docker Compose на ВМ Яндекс Облака.

## Где смотреть
- Постановка задачи (приоритет над всем) → `docs/TZ.md`
