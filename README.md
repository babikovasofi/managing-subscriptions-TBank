## Что умеет сервис

- Автоматически находит подписки в транзакциях без участия пользователя
- Показывает статус каждой подписки: активна / цена выросла / возможно не используется / пробный период
- Предупреждает о ближайших списаниях и изменении цены
- Показывает аналитику расходов и потенциальную экономию
- Позволяет управлять подписками: отметить важной, скрыть, пометить как ошибку ML, добавить вручную

---

## ML-подход

- **Гибрид:** rule-based отбор кандидатов + LightGBM классификатор
- **18 признаков:** регулярность интервалов, стабильность суммы, CV суммы, MCC-категория, длительность истории, наличие в словаре подписочных сервисов и др.
- **Датасет:** 159 синтетических клиентов, 12 месяцев истории, ~112 000 транзакций; 9 hard-negative клиентов (абонементы, рассрочка, репетиторы) для качества ML
- **Метрики (CV 5-fold по клиентам):**

| Метрика | CV (mean ± std) | Test |
|---|---|---|
| Precision | 0.995 ± 0.007 | 1.00 |
| Recall | 0.998 ± 0.003 | 1.00 |
| F1 | 0.997 ± 0.003 | 1.00 |
| ROC-AUC | 0.999 ± 0.002 | 1.00 |

- **Объяснимость:** каждая подписка содержит текстовые причины классификации на русском, отображаемые в интерфейсе

## Как запустить локально

### API
```bash
pip install -r api/requirements.txt
python -m data.generator.generate
python -m ml.models.train
python -m api.init_db
uvicorn api.app.main:app --reload --port 8000
```

### Фронт
```bash
cd web
npm install
npm run dev
```

Открыть: [http://localhost:3000](http://localhost:3000)
