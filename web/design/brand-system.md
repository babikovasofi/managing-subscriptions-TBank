## v2 — уточнено по мобильным скриншотам

| Что заметил | Решение |
|---|---|
| Тёмная тема — основной режим приложения, фон #000 | Сделал dark тему по-умолчанию, переключатель в правом углу |
| Поверхности карточек на тёмном — слегка светлее #000 | `--surface-1: #1C1C1E`, `--surface-3: #38383A` для hover/divider |
| Карточки крупные, скругление визуально ~24px | `--tb-radius-2xl: 24px` для контейнеров списков |
| Primary CTA — жёлтые, height ~56, текст ~17 medium, **почти-чёрный** на жёлтом | `--text-on-yellow: #1B1B1B` (раньше было `#333`); радиус кнопок 16 |
| Заголовки — тяжёлый геометр. гротеск, weight 800 | Manrope 800 (закрыт лицензией dsHeading — Manrope ближайший открытый аналог) |
| Иконки категорий — насыщенные круглые тайлы (фиолет/зелёный/синий/красный/жёлтый/оранжевый) | Палитра `.sub__icon--*` пересобрана на сатурированные категорий-цвета |
| Текстовые линки — синие `#428BF9` («Я уже клиент», «Отменить») | `--text-link` отличается от primary (на тёмном — `#6EA8FA` для контраста) |
| Тонких бордеров на тёмном фоне почти нет — только полупрозр. divider `#FFFFFF12` | `--divider` зависит от темы |
| Большие шрифт-размеры — display 44, h0 32 | Добавлены `--tb-fs-display`, `--tb-fs-h0` |

## 2. Типографика

**Шрифт-стек (фолбэк, dsText/dsHeading проприетарны):**

```css
--font-text:    -apple-system, BlinkMacSystemFont, "Segoe UI", "Helvetica Neue", Arial, sans-serif;
--font-heading: -apple-system, BlinkMacSystemFont, "Segoe UI", "Helvetica Neue", Arial, sans-serif;
--font-numbers: ui-rounded, "SF Pro Rounded", -apple-system, BlinkMacSystemFont, sans-serif; /* для мобильных сумм */
```

Для веба возьмём ближайший открытый эквивалент: **Inter** (text) + **Inter** или **Manrope** (heading), числа — system-rounded.

**Шкала размеров (как в TUI, рендеримая на 1× с font-offset = 0):**

| Токен | Size / LH | Weight |
|---|---|---|
| heading-1 | 50 / 56 | 700 |
| heading-2 | 44 / 48 | 700 |
| heading-3 | 36 / 40 | 500 |
| heading-4 | 28 / 32 | 500 |
| heading-5 | 24 / 28 | 500 |
| heading-6 | 20 / 24 | 500 |
| text-xl / xl-bold | 19 / 28 | 400/500 |
| text-l / l-bold | 17 / 28 | 400/500 |
| text-ui-l | 17 / 24 | 400 |
| **text-m / m-bold** ⭐ | 15 / 24 | 400/500 — базовый body |
| text-ui-m | 15 / 20 | 400 |
| text-s / s-bold | 13 / 20 | 400/500 |
| text-ui-s | 13 / 16 | 400 |
| text-xs | 11 / 16 | 400 — caps/caption, letter-spacing 0.4 |

**Для мобильного экрана 430px я смещу базу:** body = 15px, мелкие подписи = 13px, заголовок секций = 17–20px, цена — 28px полужирная rounded.

## 3. Радиусы

В дизайн-системе нет явного `--radius-*` токена. Эмпирически из карточек захвата:

| Уровень | Значение |
|---|---|
| chip / tag / иконка-плашка | `8px` |
| button | `12px` (для мобильного — `12px` или `16px` на больших) |
| card (стандартная) | `12px` |
| card (hero, sheet) | `16px–24px` |
| bottom-sheet (top) | `24px 24px 0 0` |
| pill / segmented control | `999px` (full) |

## 5. Кнопки (правила)

- **Primary (yellow):** bg `#FFDD2D`, text `#333333`, weight 500, radius 12, height 48–56 на мобильном, без тени. Hover `#FFCD33`, pressed `#FAB619`.
- **Primary on dark:** bg `#FFFFFF`, text `#000000CC`.
- **Secondary / ghost:** bg `#244A7F0F` (нейтраль), text `#000000CC`, radius 12.
- **Link / text-button:** color `#428BF9`, hover `#126DF7`, без подложки.
- **Destructive:** bg `#F52222`, text `#FFFFFF` (или ghost: text `#F52222` на `#F5222224`).
- Минимальная высота tap-target — **48 px**.

## 6. Что зафиксировано в коде

- `tokens.css` — все переменные выше, готовы к подключению.
- Имена префиксированы `--tb-*` (не `--tui-*`, чтобы не конфликтовать с реальной TUI).
